# 🎹 Hackpad

A custom macropad designed and built as part of the **Hack Club Stardance Hackpad Mission**.

## 📖 About

Hackpad is a small custom keyboard/macropad designed to provide a set of programmable buttons for quickly performing common actions.

The project focuses on designing the hardware from scratch, creating the PCB, assembling the components, and programming the macropad.

## 🎯 Goals

* Design a custom macropad PCB
* Create a functional and compact keyboard
* Program each key to perform a specific action
* Learn the basics of PCB design and electronics
* Build and test the hardware myself

## 🛠️ Hardware

The project uses:

* Custom PCB
* Mechanical keyboard switches
* Keycaps
* Microcontroller
* Diodes
* USB connection
* Other required electronic components

## 💻 Software

The firmware will be responsible for:

* Detecting key presses
* Mapping keys to specific functions
* Sending keyboard commands to the computer

## 🔧 Design & Build Process

The project is being developed through the following stages:

1. 💡 **Idea** — Define the purpose and layout of the macropad.
2. 📐 **Schematic** — Design the electronic circuit.
3. 🧩 **PCB Design** — Create and route the custom PCB.
4. 🏭 **PCB Manufacturing** — Manufacture the designed PCB.
5. 🔨 **Assembly** — Solder and assemble the components.
6. 💻 **Firmware** — Program the macropad.
7. 🧪 **Testing** — Test every key and fix any hardware or software issues.
8. 🚀 **Final Build** — Complete and document the finished Hackpad.
